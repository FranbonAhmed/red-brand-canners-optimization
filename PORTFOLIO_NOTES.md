# Portfolio Notes

## Source vs portfolio extensions

This repository distinguishes between results reported in the submitted graduate workshop and work added later for professional presentation.

### Source-derived work
- Base linear programming formulation and optimal product mix
- Shadow-price / sensitivity interpretation
- Additional Grade A purchase decision
- Advertising-value analysis
- Additional Grade B marginal-value decision
- Enumeration of production-line combinations under $50,000 setup costs
- Scenario analysis and 50,000-lb grid search for the contracting quantity

### Portfolio extensions
- Reorganized recruiter-facing notebook and README
- Professional charts generated from the submitted results
- Fixed-charge MILP formulation replacing brute-force line enumeration
- Continuous visualization of expected profit across the same tested 50,000-lb contract grid

## Numerical source of record

The submitted report is treated as the source of record for headline results. Portfolio calculations are labeled as extensions and are used only when they reproduce or visualize the same documented model.
